# knife — Bybit Trading Bot

Автоматический торговый бот для USDT-перпетуалов Bybit. Ловит памп/дамп, 
определяет пин-бары на уровнях поддержки/сопротивления, торгует по системе 
сеточного усреднения с ступенчатым выходом.

## ⚠️ ВАЖНО: Реальная торговля

Бот торгует **реальными средствами** на Bybit. Для работы необходимы:
- API ключи с правами Read + Trade
- USDT баланс на аккаунте Bybit
- Настроенные `.env` с `BYBIT_API_KEY` и `BYBIT_API_SECRET`

Подробнее: [API_SETUP.md](API_SETUP.md)

## Локальный запуск (Windows)
```bat
cd C:\Users\Canon\Projects\Knife
python -m venv .venv
.venv\Scripts\activate
pip install -r requirements.txt
copy .env.example .env
uvicorn app.main:app --host 127.0.0.1 --port 8000 --reload
```

## Режимы торговли

- **Скальпинг (5m)** — быстрые сделки, низкие комиссии, высокий риск
- **Интрадэй (15m)** — баланс риска и прибыли
- **Долгосрок (4H)** — редкие сделки, большие цели, ниже риск

## Настройка параметров

В интерфейсе бота доступны:
- `position_size_entry` — размер позиции при входе (USDT)
- `position_size_grid` — размер позиции при усреднении (USDT)
- `max_open_trades` — максимум одновременно открытых сделок
- `grid_step_pct` — шаг сетки усреднения (%)
- `initial_exit_pct` — начальная цель выхода (%)
- `check_validity_before_grid` — проверять разворот перед усреднением

## Мониторинг

Бот показывает:
- Реальный баланс с Bybit
- Реализованный и нереализованный PnL
- Открытые сделки с сеткой усреднений
- Закрытые сделки со статистикой
- Сигналы пампа/дампа
